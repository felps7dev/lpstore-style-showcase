# LP Store Digital Showcase

Crie uma VITRINE DIGITAL PREMIUM E INTERATIVA para a loja LP STORE, localizada em Batista Campos, Belém - PA.

ESTE É UM PROJETO DEMONSTRATIVO PARA APRESENTAÇÃO AO PROPRIETÁRIO DA LOJA.

Não quero um e-commerce completo.

Não criar login, cadastro, carrinho, checkout ou sistema de pagamento.

O objetivo é criar uma experiência digital moderna que apresente a LP STORE, seus produtos e principalmente conduza o visitante para o WhatsApp.

A experiência deve parecer uma vitrine digital de uma marca de moda/streetwear premium.

==================================================

IDENTIDADE VISUAL

==================================================

Usar a LOGO DA LP STORE fornecida como referência principal.

Manter a identidade existente da marca.

Paleta visual:

- preto como cor predominante;

- branco para textos;

- dourado como cor de destaque;

- utilizar o dourado com moderação e elegância.

Estética:

- streetwear;

- premium;

- moderna;

- masculina;

- sofisticada;

- urbana;

- visual editorial de moda.

Evitar aparência de template genérico.

Não alterar a logo.

Criar uma identidade visual consistente entre todas as seções.

Usar tipografia moderna, forte e elegante.

==================================================

1. HEADER

==================================================

Criar um header elegante.

Logo LP STORE à esquerda.

Menu:

INÍCIO

PRODUTOS

SOBRE

CONTATO

Botão destacado:

FALAR NO WHATSAPP

No mobile, transformar o menu em menu hamburger.

O header deve permanecer funcional e responsivo.

==================================================

2. HERO — EXPERIÊNCIA INTERATIVA

==================================================

Esta deve ser a parte mais impressionante do projeto.

Criar um HERO cinematográfico e interativo.

Título principal:

"SEU ESTILO.

SUA ESCOLHA."

Subtexto:

"Streetwear, tênis e peças premium selecionadas para quem não abre mão do estilo."

Botões:

VER PRODUTOS

FALAR NO WHATSAPP

Adicionar um produto da LP STORE em destaque, preferencialmente um tênis ou peça de roupa presente nas imagens fornecidas.

O produto deve aparecer grande e visualmente impactante.

CRIAR UMA EXPERIÊNCIA DE PRODUTO CONTROLADA PELO SCROLL.

Conforme o usuário rola a página:

1. O produto aparece grande no Hero.

2. O produto começa a se mover suavemente.

3. Aplicar uma pequena rotação.

4. Aplicar leve efeito de zoom.

5. Utilizar parallax.

6. O produto deve se deslocar pela tela acompanhando a progressão do scroll.

7. Textos curtos aparecem durante a experiência:

"STREET STYLE"

depois:

"LINHA PREMIUM"

depois:

"SEU ESTILO"

8. Conforme o usuário continua rolando, o produto deve diminuir e se deslocar em direção à próxima seção.

9. O produto deve terminar visualmente integrado à seção "DESTAQUES DA LP STORE", como se estivesse entrando em um card de produto.

A transição deve ser suave e parecer uma campanha de moda moderna.

IMPORTANTE:

Não utilizar 3D pesado.

Preferir:

CSS

JavaScript

transform

parallax

scroll animation

GSAP ou tecnologia equivalente, somente se realmente necessário.

Priorizar performance.

No celular, adaptar a animação para touch/scroll vertical.

A animação nunca deve bloquear os botões ou prejudicar a navegação.

==================================================

Criar uma seção:

"DESTAQUES DA LP STORE"

Mostrar apenas 6 produtos demonstrativos.

Não inventar produtos específicos se não houver imagens disponíveis.

Usar prioritariamente as imagens reais fornecidas.

Cada produto deve possuir:

- imagem;

- nome;

- categoria;

- botão "TENHO INTERESSE".

NÃO INVENTAR PREÇOS.

Não colocar preço caso ele não tenha sido fornecido.

Ao clicar em "TENHO INTERESSE", abrir o WhatsApp com uma mensagem pré-preenchida:

"Olá! Vi este produto na vitrine da LP Store e gostaria de saber a disponibilidade e o valor."

Usar o número:

+55 91 93817-161
